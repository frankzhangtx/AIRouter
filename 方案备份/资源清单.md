# 备份资源清单

## 1. 仓库入口与集成配置

| 原路径 | 备份路径 | 用途 |
| --- | --- | --- |
| `.gitignore` | `snapshot/repository/ROOT.gitignore` | 排除版本化目录中的运行态 state/evidence/locks |
| `AGENTS.md` | `snapshot/repository/AGENTS.md` | Android 构建、测试和安全执行约定 |
| `opencode.json` | `snapshot/repository/opencode.json` | 固定 Scheduler 和 Superpowers 插件来源 |
| `.opencode/.gitignore` | `snapshot/repository/.opencode/OPENCODE.gitignore` | OpenCode 本地依赖忽略规则 |
| `.opencode/package.json` | 同相对目录 | 固定 `@opencode-ai/plugin@1.15.13` |
| `.opencode/package-lock.json` | 同相对目录 | 精确 npm 依赖锁 |

两份 `.gitignore` 在备份中有意改名，防止它们继续影响备份目录自身的 Git
收集。恢复时必须按“原路径”名称写回。

## 9. 运行审计副本（79 个文件）

目录：`runtime-audit/automation-runtime/`

它对应备份时的 `.git/automation-runtime/`，包含三个已完成任务的：

- 状态 JSON；
- workspace 绑定；
- 原分支、基线、RED、质量门和 Reviewer 证据；
- sealed diff、验收报告、集成验证和 cleanup 日志；
- 追加式 approvals、transitions、reviews 和 agent-runs 审计。

该目录用于审计，不属于可移植插件模板，也不应默认恢复到另一仓库。

## 10. 有意不复制的内容

- `.opencode/node_modules/`：约 57 MB，可由备份的 package/lock 重建；复制它
  会混入大量平台相关二进制依赖。
- Android 产品源码、资源和 Gradle 工程：它们是自动化的受保护宿主输入，
  不是自动化方案实现；插件化改造不应修改它们。
- `.env`、`local.properties`、签名文件和密钥：既非方案资源，也不得进入备份。
- 完整 `.git` 对象库和 refs：只复制了自动化运行审计；Git 历史仍由仓库承担。
- macOS launchd 任务：V3 正常流程不依赖定时任务，之前取消的任务不会通过
  本备份重新注册。
